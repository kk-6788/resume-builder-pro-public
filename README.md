# 简历工作台 · Resume Studio

> 用 vibe coding 做的**离线简历工作台**：Windows EXE + 网页版，纯本地运行，零服务器，简历不离开你的电脑。
> 帮人改简历 / 简历代做 / 简历接单，3 分钟出一份 85 分简历。

## 这是什么

一个所见即所得的简历工具：左侧编辑，右侧实时渲染 A4 简历。

- **导入材料**：PDF / Word（.docx）/ 图片（PNG/JPG/WebP）/ 直接粘贴文字，自动解析预填，识别结果先核对再建稿
- **13 套版式**：版式选择显示真实示意缩略图，右侧实时预览自己的内容；含双栏商务/表格经典/高级留白/现代杂志/清新多彩/技能仪表（进度条）等
- **岗位模板**：17 个常见岗位一键填充（文员/行政/新媒体/电商/运营/人力/会计/客服/销售/产品实习/数据分析/设计/剪辑/开发/教师/护士/医药销售）
- **AI 工具箱**：整份润色 / 单条润色 / 自我评价 / 找出材料缺口（贴 JD 回答关键问题）/ 逐条修改建议，支持 DeepSeek / Agnes / 自定义 OpenAI 兼容服务
- **为新岗位创建副本**：填写新岗位和 JD，保留原稿，新副本重新核对与评分
- **5 维 85 分质量检查**：岗位匹配 25 + 经历与贡献 25 + 信息完整 20 + 表达质量 15 + 排版可读性 15，每条扣分带原文依据和改法
- **条目上下移动 + 历史快照**：每个条目可排序，每份简历保留最近 5 个修改前快照，可恢复
- **导出**：PDF / 可编辑 Word / 带水印预览图 / 纯文字 TXT（按显示顺序核对用，不含备注与照片）
- **本地数据**：IndexedDB 保存，备份导出 JSON（不含 API Key），恢复以新 ID 加入不覆盖

## 快速开始

```bash
# 方式一：网页版（什么都不用装）
git clone https://github.com/kk-6788/resume-builder-pro-public.git
cd resume-builder-pro-public
# 双击 index.html 即可（Chrome/Edge 最佳）
```

```bash
# 方式二：Windows 桌面版（Electron）
npm ci
npm run build        # 输出 outputs/简历工作台-2.1-Windows，双击 EXE 使用
```

**AI 功能可选**：在「AI 设置」里填自己的 Base URL / 模型 / Key（DeepSeek、Agnes 或任意 OpenAI 兼容服务），不填也能完成编辑、导入、Word/图片导出与本地质量检查。密钥只存本机，不随备份导出。

## 85 分标准

| 维度 | 分数 | 检查方式 |
|---|---:|---|
| 岗位匹配 | 25 | 5 项 AI 证据审查 |
| 经历与贡献 | 25 | 5 项 AI 证据审查，不强求量化 |
| 信息完整与一致 | 20 | 本地检查姓名、联系、岗位、教育、经历、年月及占位符 |
| 表达质量 | 15 | 3 项 AI 证据审查 |
| 排版与可读性 | 15 | 实际页面文字、溢出和预计页数 |

**总分至少 85、且没有必须修正的问题、已提供 JD 并确认真实性，才标记交付达标。** 没有有效 AI 审查时只显示本地部分分数，绝不伪造总分。分数是工作台内部质量门槛，不是录用概率。

## 建议工作流程

1. 新建简历，或导入 PDF / DOCX / 截图 / 粘贴文字
2. 对照原材料核对提取结果，确认后新建简历，不覆盖已有客户资料
3. 填写目标岗位，粘贴 JD，点击「找出材料缺口」，回答最多 5 个关键问题
4. 运行整份或单条润色，逐项对比、勾选确认后应用；AI 新增原文没有的数字会被拒绝
5. 在「排版」中选择 13 种版式，调整模块顺序、隐藏、配色、字号、间距
6. 核对事实、勾选真实性确认，运行完整质量检查
7. 导出 PDF / Word / 带水印预览图 / 纯文字 TXT

## 接单玩法（闲鱼定制服务）

```
客户发需求 → 导入材料/填信息 → 贴 JD 跑「找出材料缺口」→ 润色 → 质量检查 ≥85
→ 带水印预览图确认 → 确认后导出 PDF/Word → 交付
```

## 给 AI Agent 用（安装 skill）

```bash
./install.sh   # 把 SKILL.md 复制到 ~/.claude/skills/ 或指定目录
```

装好后在 Claude Code / Hermes 里说「帮我做一份XX岗位的简历」「帮我改简历」即触发。

## 开发与测试

```bash
npm ci
npm test               # node --test tests/*.test.cjs
npm run vendor         # 重新生成 vendor 依赖
npm run preview        # 本机预览（只暴露 index.html 与 app/、vendor/）
```

代码模块：`core.js` 管数据与评分，`app.js` 管交互，`render.js`/`resume.css` 管预览，`ai.js` 管 AI，`services.js` 管文件，`desktop/` 管 Electron 外壳。

## 隐私

所有数据只存在本机（IndexedDB / 本地存储）。AI 功能会把相关经历文本发给你自己配置的服务商处理（可选）。无登录、无云同步、无追踪。第三方库授权见 `vendor/*-LICENSE.txt`。

### 恢复备份与备用存储

超过本机 300 份容量的备份会分批恢复。成功保存当前批次后，浏览器会下载“简历备份-剩余N份.json”，只包含尚未恢复的记录。请确认文件已下载，备份并整理本机简历后，导入这个剩余文件继续；重新导入原文件会从头追加。若保存失败，不会导出剩余文件或把未保存的导入留在列表中，请先解决存储问题再重试。

IndexedDB 恢复可用后会检查以前的 localStorage 备用库。主库为空时自动迁移；两个库都有不同内容时，请选择要恢复的版本。备用库仅在主库事务成功提交且备用内容未被另一窗口修改后清理，失败时原数据保留。
