# GitHub 参考与 2.1 改进计划

查阅日期：2026-09-13。基于公开仓库 README 的功能说明进行产品参考，以下实现由本项目独立编写，没有引入第三方项目代码或依赖。

| 来源 | 实际参考点 | 本项目采用方式 |
|---|---|---|
| [Reactive Resume](https://github.com/reactive-resume/reactive-resume) | 多模板、实时预览、模块排序 | 七种模板改为真实渲染的示意缩略图；添加条目上下移动 |
| [OpenResume](https://github.com/xitanggg/open-resume) | 本地运行、PDF 导入、文字解析可读性检查 | 增加当前简历的纯文字核对和 TXT 导出，用于检查内容、复制到招聘网站 |
| [Resume Matcher](https://github.com/srbhr/Resume-Matcher) | 主简历派生岗位定制稿、JD 定制、逐项审核改进 | 增加“为新岗位创建副本”，明确输入岗位和 JD，原稿保留，新稿重新审查 |

纯文字视图来自当前结构化数据，尊重隐藏模块与顺序，不等于第三方 ATS 或导出 PDF 的解析结果；不新增伪精确分数。岗位副本不自动编写经历。继续使用现有 85 分门槛、每份最近 5 个快照和最小 10pt 排版。

## 实施与验证

- 在 `core.js` 增加纯文字序列化和岗位副本构造函数；测试隐藏字段、排序、熟练度、素材隔离和原稿独立性。
- 在 `app.js` 增加条目移动、岗位副本表单及文字核对弹窗；测试移动后历史恢复、评分失效、取消不新建、文字转义和导出确认。
- 模板缩略图复用 `render.js` 和 `resume.css` 渲染固定演示材料；`style.css` 提供缩放容器与选中状态。用户材料不被缩略图改写。
- 更新 README、版本与分发脚本；运行单元与 DOM 测试，实际 Electron 验证 PDF/Word/PNG 和桌面、手机布局。
- 新交付保存到当天交付目录。旧文件只在用户明确删除范围后处理；原项目中的客户简历、照片及用户应用数据不作推定删除。
